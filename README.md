
# Competitive Programming with C++ 🎯

A structured repository containing my solutions to various algorithmic problems from online judges and competitive programming contests. Built and tested using **Code::Blocks**.

## 📊 Platform Coverage
- **Codeforces** (ICPC Assiut University Training Sheets & Active Contests)
- **LeetCode** / **HackerRank**
- **Beecrowd** / **URI Online Judge**

## 📂 Directory Organization
- `Contests/` - Solutions grouped by active contest IDs.
- `Problemset/` - Topic-wise solved problems (Greedy, Math, DP, Graphs).
- `Templates/` - Fast I/O boilerplate and pre-written macro layouts for rapid coding.

## ⚡ Tech Stack
- **Language:** Highly optimized C++ (MinGW GCC)
- **Execution:** Fast I/O standard template execution
